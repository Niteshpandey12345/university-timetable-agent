What each agent contributes ttagent agent-eval

Every task runs end-to-end through the LangGraph workflow and the four MCP server processes, on a fresh database. Some tasks inject a fault into the scheduling tool: silent corruption (it reports a valid timetable that has clashes), a starved solver (1 s budget) or a tool outage (the first calls fail). A simulated officer approves whatever the system shows. Success and safety are judged by an independent validation of the final database, never by the agent's own answer.
